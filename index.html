Use the file in Audacity

    
  1. Build the file here and inspect the first few rows.
  2. Download the TXT. In Audacity, use File → Import → Labels, or the Label Editor’s import control.
  3. Check a few point and region labels against your recording before using the whole track.

    
This helper creates text only, not SRT/VTT subtitles or extended frequency-range labels. Existing spreadsheet and script workflows are alternatives; no unique compatibility or timing accuracy is promised.

  

  

    
Explicit limits
Up to 1,000 data rows and 256 KiB of UTF‑8 input; times from zero to 604,800 seconds, with at most six fractional digits. Labels must be nonblank and no longer than 200 UTF‑16 code units. Tabs, line breaks and control characters in labels are rejected, not silently removed.

    
Your text stays here
The application sends no input text over the network, uses no analytics or persistent storage, and does not open audio. Loading the page’s own files still uses the hosting service. The app does not save your text; keep your own copy before leaving.
